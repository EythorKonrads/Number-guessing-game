# Number Guessing Game (React + TypeScript)

A simple **number guessing game** built with **React + TypeScript**.  
The goal is to guess the secret number (between 1 and 100) in **10 attempts or less**.  
If you win, you can **save your score** to the **local scoreboard**, which keeps track of your total games and top results — all stored in your browser via **localStorage**.

## Install dependencies:
`npm install`

## Start the development server:
`npm run dev`
